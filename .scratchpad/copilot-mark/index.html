Copilot mark directions

Ten options for a Copilot mark that sits in the same family as the LlamaTrade candlestick logo. Each one uses the logo's construction: a 32 by 32 grid, 3.2 wide candle bodies with a 0.5 corner radius, 1.1 wicks (1.4 when bold), currentColor for the ink and the accent token for one small detail. None of them reuse the llama silhouette.

Large sizes (96 and 44) use the bold weight, the same way the Copilot hero uses LogoMark bold today. 24 and 16 use the regular weight unless a mark notes otherwise.
