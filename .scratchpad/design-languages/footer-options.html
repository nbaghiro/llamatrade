Five footers for the bottom of the marketing site. Each one is drawn with the site's own CSS and tokens, below the Join section as it appears on the page. The Light and Dark switch here and the one in each footer change the whole page.

All five put the columns, the divider and the bottom row on one 12-column grid inside the 1200px wrap, use the Overhang lockup and fill the theme switch with ink. The Learn column stays out until Documentation and Strategy language have pages, as the current footer does.

AClosing lockup

Recommended
Good at

Ends the page the way it opens: the Overhang lockup at display size, centred over the same rising candle chart as the hero, with the accent moving average drawing in. The ink pill buttons repeat the two actions without a second email field, and the links, disclaimer and bottom row sit on one grid below.

Costs

The tallest option, about 750px at 1440 wide. It adds one more drawn chart to the page, and SectionArt would need to anchor on the closing block instead of an h2. An inline email pill would fit here too, but it would repeat the Join form a screen above.
